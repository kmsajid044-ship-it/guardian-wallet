# Licenses

Guardian Wallet is released under the MIT License (`LICENSE`). This file lists every third-party component it uses. It is generated by `pnpm licenses:doc` from the installed dependency tree, so versions and licenses are the ones actually resolved by `pnpm-lock.yaml`.

- npm packages: **222** installed (direct and transitive), of which **79** are runtime dependencies of a workspace; the rest are build, test, and lint tooling.
- Copyleft licenses among npm packages: no strong copyleft (GPL, LGPL, AGPL); weak (file-level): `lightningcss` (MPL-2.0, build or development only), `lightningcss-darwin-arm64` (MPL-2.0, build or development only).
